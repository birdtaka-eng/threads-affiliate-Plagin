# Threads GAS 自動投稿 + 自己進化AI (v2.0)

## 概要
Google Sheets で Threads の予約投稿を管理し、**「いいね数」を分析してAIペルソナを自動進化させる** システムです。

## セットアップ

### 1. スクリプト設定
- `Code.js` の内容を GAS プロジェクトにコピペしてください。

### 2. スプレッドシート構成

#### シート名: `設定`
| セル | 項目 | 内容 |
| :--- | :--- | :--- |
| **B2** | User ID | Threads User ID |
| **B3** | Access Token | 長期アクセストークン |
| **B4** | API Key | Gemini API Key |
| **B5** | Persona | **(固定)** AIのキャラ設定 (Who) |
| **B6** | Style Rule | **(自動進化)** 表現のルール、文体 (How) |

#### シート名: `投稿リスト`
| 列 | 項目名 | 使用用途 |
| :--- | :--- | :--- |
| **A** | 投稿日時 | 予約時間 |
| **B** | (任意) | メモ用など |
| **C** | 投稿本文 | 投稿テキスト |
| **D** | 画像URL | **(New)** 複数枚ならカンマ区切り |
| **E** | ステータス | 「待機」「完了」 |
| **F** | ネタ | AI生成用の元ネタ |
| **G** | タイプ | AIへの指示 |
| **H-J** | 生成案 | AI生成出力 |
| **K** | **Post ID** | **(自動)** 追跡ID |
| **L** | **Likes** | **(自動)** いいね数 |
| **M** | **Views** | **(自動)** 閲覧数 |
| **N** | **Replies** | **(自動)** 返信数 |
| **O** | **Reposts** | **(自動)** 再投稿数 |
| **P** | **Quotes** | **(自動)** 引用数 |

#### シート名: `楽天アフィリエイト工場` (v3.2 New)
アフィリエイト記事を量産するための専用工場です。

| 列/セル | 項目名 | 使用用途 |
| :--- | :--- | :--- |
| **A** | **URL** | **(入力)** 楽天Roomの商品URL (`a.r10.to` 推奨) |
| **B** | **Image** | **(自動)** 画像URLが出力されます |
| **C** | **Text** | **(自動)** 紹介文+リンクが出力されます |
| **D** | **Status** | 「完了」などが自動で入ります |
| **E** | **Hint** | **(任意)** 個別の指示メモ (例:「北欧風であることを強調」) |
| **F2** | **Prompt**| **(任意)** 全体に共通するプロンプト指示書をここに置けます |

## 使い方 (v3.2 Rakuten Factory 🏭)

1. **URL収集**: 楽天Roomで紹介したい商品の「短縮URL (`a.r10.to`)」をコピーし、`楽天アフィリエイト工場` の **A列** にひたすら貼り付けます。
    - もし「こういう風に紹介してほしい」という希望があれば、**E列(Hint)** にメモを書いておくとAIがそれを参考にします。
2. **一括製造**: メニュー「✨ AI生成エンジン」>「**楽天記事を一括製造**」を実行します。
3. **完成**: B列に画像、C列に文章(リンク付)が出来上がります。
4. **出荷**: 良いものをコピーして、メインの `投稿リスト` のC列・D列に貼り付けてください。

### 🌟 詳細インサイトモード (v3.0)
「✨ AI生成エンジン」>「投稿成績を更新」を実行すると、**L〜P列 (いいね, Views, 返信, リポスト, 引用)** が一気に埋まります。
「どの投稿が見られたか(Views)」「どれが拡散されたか(Reposts)」を分析できます。

### 🎞️ カルーセル投稿
D列（画像URL）に、複数のURLを **改行区切り** または **カンマ区切り** で入力してください。
自動的にスワイプ式の「カルーセル投稿」として予約されます。
（例: `https://...image1.jpg, https://...image2.jpg`）

## トリガー設定
- `checkAndPost` を「時間主導型 / 10分おき」などに設定してください。
