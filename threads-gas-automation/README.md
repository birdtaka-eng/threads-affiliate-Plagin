# Threads GAS 自動投稿 + 自己進化AI (v2.0)

## 概要
Google Sheets で Threads の予約投稿を管理し、**「いいね数」を分析してAIペルソナを自動進化させる** システムです。

## セットアップ

### 1. スクリプト設定
- `Code.js` の内容を GAS プロジェクトにコピペしてください。

### 2. スプレッドシート構成

#### シート名: `設定`
| セル | 項目 | 内容 |
| :--- | :--- | :--- |
| **B2** | User ID | Threads User ID |
| **B3** | Access Token | 長期アクセストークン |
| **B4** | API Key | Gemini API Key |
| **B5** | Persona | **(固定)** AIのキャラ設定 (Who) |
| **B6** | Style Rule | **(自動進化)** 表現のルール、文体 (How) |

#### シート名: `投稿作成ボード` (旧 投稿リスト)
「放送局の調整卓」のようなイメージで、投稿を管理するメイン画面です。

| 列 | 項目名 | 役割 |
| :--- | :--- | :--- |
| **A** | **ON AIR** | **(重要)** ここにチェック✅を入れると「放送待ち」状態になります。番組表の時間になると、ここから自動でピックアップされます。 |
| **B** | No | 管理番号 |
| **C** | **Type** | 投稿の種類 (単品/日常/有益/まとめ/Free) |
| **D** | **Humor** | ユーモアレベル (Lv1:知的 〜 Lv3:爆笑) |
| **E** | **Topic** | **(入力)** ネタやメモを書く場所。Freeタイプの場合は、ここが推敲元の文章になります。 |
| **F** | Assets | 画像URLやリンクのメモ用 (AI生成には影響しません) |
| **G** | **Output** | **(生成)** AIが書いた投稿本文が出力されます。手直しOK。 |
| **H** | **Selector** | **(便利)** 「案1」「案2」「案3」を切り替えると、G列の文章が瞬時に切り替わります。 |

**使い方の流れ:**
1. **Topic** にネタを書く。
2. メニュー「✨ AI生成エンジン」>「投稿一括生成」を実行。
3. AIが3パターン作成するので、**Selector** で好きな案を選ぶ。
4. 内容が良ければ **ON AIR** にチェックを入れる。→ 放送予約完了！

---

#### シート名: `番組表` (New!)
「何曜日の何時に、どのジャンルを放送するか」を決めるスケジュール表です。

- **縦軸**: 時間帯 (8:00〜23:00)
- **横軸**: 曜日 (月〜日)
- **セル**: 放送する「Type (日常/有益など)」を選択します。

**自動放送の仕組み:**
1. 例えば「月曜 12:00」の枠に「**日常**」がセットされているとします。
2. 時間になると、ボットが『投稿作成ボード』を見に行きます。
3. **ON AIR** になっていて、かつ **Typeが「日常」** の投稿を探し、一つピックアップしてThreadに投稿します。
4. 投稿されたものは、ON AIRのチェックが外れます。

---

#### シート名: `バズ研究所` (New!)
バズった他人の投稿を分析し、その「文体(DNA)」をコピーするための研究施設です。

| 列 | 項目名 | 使い方 |
| :--- | :--- | :--- |
| **A** | Type | その投稿のジャンル (日常/有益など) |
| **B** | Image Context | 画像が含まれていた場合、どういう写真だったかメモ (例: 猫が寝ている写真) |
| **C** | **Raw Post** | **(入力)** バズった投稿の本文をそのまま貼り付けます。 |
| **D** | **DNA** | **(自動)** AIが解析し、「バズりの法則(DNA)」を抽出して書き込みます。 |

**DNAの効果:**
ここで抽出されたDNAは、自動的に全投稿の生成時に「隠し味」として参照されるようになります。
（学習させればさせるほど、AIの引き出しが増えます）

---

#### シート名: `楽天アフィリエイト工場`
アフィリエイト記事を量産するための専用工場です。
(使い方は変更ありません。Roomの短縮URLを貼り付けて一括製造してください)

## 使い方 (全体フロー)

1. **【仕入れ】** `バズ研究所` で良い投稿を分析させたり、`楽天工場` で商品記事を作る。
2. **【編成】** `番組表` で、放送したい時間をセットする。
3. **【制作】** `投稿作成ボード` でネタを書き、AIで生成し、良いものに **ON AIR** する。
4. **【放送】** あとは放っておけば、番組表通りに自動放送されます。
